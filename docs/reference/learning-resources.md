# Tài nguyên học chính chủ

Nguồn học miễn phí từ JetBrains và Google, dùng kèm lộ trình khi muốn học sâu thêm Kotlin hoặc luyện tay.

## Kotlin for Education

**[kotlinlang.org/education](https://kotlinlang.org/education/)**: cổng giáo dục chính thức của Kotlin. Trang này viết chủ yếu cho giảng viên, nhưng người tự học vẫn dùng được nhiều thứ:

| Phần | Có gì | Dùng khi nào |
|---|---|---|
| Teach Computer Science with Kotlin | Slide khoảng 12 chủ đề: OOP, generics, collections, lập trình hàm, concurrency, testing, build system | Muốn hiểu Kotlin bài bản như một môn học, không chỉ học theo kiểu "làm được là xong" |
| Backend Development with Kotlin | Slide + project demo trên GitHub | Muốn dùng lại kiến thức Kotlin cho backend (Ktor) |
| Bài tập + đề kiểm tra | Syllabus, quiz, homework | Tự kiểm tra sau mỗi chặng của lộ trình |
| Giấy phép giáo dục | License JetBrains miễn phí cho học sinh, sinh viên, giảng viên | Nếu đang đi học: dùng IntelliJ IDEA Ultimate miễn phí |

## Luyện tay

- [Kotlin tour](https://kotlinlang.org/docs/kotlin-tour-welcome.html): đi nhanh toàn bộ cú pháp Kotlin, nên đọc trước bài 1.
- [Kotlin Koans](https://play.kotlinlang.org/koans/overview): bài tập nhỏ chạy ngay trên trình duyệt.
- [Kotlin Playground](https://play.kotlinlang.org/): chạy thử code mà không cần cài gì.
- [Atomic Kotlin](https://www.atomickotlin.com/): sách + bài tập, đi từ con số 0.

## Kotlin Multiplatform

- [Kotlin Multiplatform docs](https://kotlinlang.org/docs/multiplatform/get-started.html): xem [Bản đồ docs chính chủ](docs-map.md) để biết trang nào ứng với bài nào.
- [KMP learning resources](https://kotlinlang.org/docs/multiplatform/kmp-learning-resources.html): danh sách khóa học, mẫu và bài viết JetBrains chọn sẵn.
- [KMP samples](https://kotlinlang.org/docs/multiplatform/multiplatform-samples.html): project mẫu để đọc code thật. Danh sách đã chọn lọc và gắn theo bài: [Repo mẫu tham khảo](sample-repos.md).

## Android (từ Google)

- [Android Basics with Compose](https://developer.android.com/courses/android-basics-compose/course): khóa nền tảng Android + Jetpack Compose.
- [Android Development with Kotlin](https://developer.android.com/courses): các khóa Kotlin cho Android.
