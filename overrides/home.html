Năm luật khi học

Chạy được mới tính. Mỗi bài kết thúc bằng app chạy trên máy, không dừng ở "đã đọc".
Logic chung trước. Đưa vào commonMain mọi thứ không dính UI hay API riêng của máy.
Ít expect/actual. Ưu tiên interface + truyền vào; expect/actual chỉ cho chỗ thật sự khác.
Dùng wizard. Đừng tự gõ Gradle từ đầu — tạo bằng wizard rồi đọc hiểu file sinh ra.
Docs gốc là chuẩn. Phiên bản đổi nhanh; lệch với site này thì tin docs của Kotlin.
